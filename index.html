Mode d'emploi
  1. Exporte tes articles depuis Lightspeed (Back Office, page Articles, Exporter), en CSV ou Excel. Refais-le avant chaque mise à jour pour partir des prix du jour.
  2. Glisse l'export dans la case 1, puis la facture PDF MD Boissons dans la case 2.
  3. Vérifie les liaisons (colonne "Article Lightspeed lié"). Une seule fois par produit, c'est mémorisé ensuite. Pour les spiritueux, lie à l'article "Bouteille X", pas au verre.
  4. Lis la colonne Évolution : ▲ hausse, ▼ baisse par rapport au prix de revient Lightspeed.
  5. Ajuste les prix de vente si besoin dans la case "Nouveau PV" (ou clique "coef maintenu" pour garder la même marge malgré la hausse).
  6. Clique "Fichier pour Lightspeed File import" : il contient les nouveaux prix de revient et prix de vente, uniquement pour les articles qui changent. Tout le reste des fiches est recopié à l'identique.
  7. Dans Lightspeed : Import, File import (new), envoie le fichier .xlsx et valide. Vérifie ensuite une ou deux fiches articles.
  8. Enregistre dans le référentiel pour garder l'historique des prix fournisseur.
Attention : utilise toujours File import, jamais Price only (qui ne connaît pas le prix de revient et peut effacer des prix de vente). Et réexporte depuis Lightspeed le jour même : l'outil refuse un export d'un autre jour.

Les données (export, liaisons, référentiel) restent dans ce navigateur uniquement.
